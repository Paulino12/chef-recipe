# Connaught Care Homes Fee Structure Proposal

## Recommended Positioning

The easiest proposal for leadership to approve is a low-risk pilot.

That keeps the decision simple:

- small upfront commitment
- clear test period
- measurable practical value
- easy path to wider rollout if the pilot works

## Recommended Option: Pilot First

### 60-Day Pilot

- GBP 295 per month
- up to 2 homes included
- no long-term contract during the pilot

Included:

- hosting
- user access setup
- manager support
- bug fixes
- minor improvements based on feedback
- mobile and web access for day-to-day use

### Optional Setup And Onboarding

- GBP 350 one-off

This can cover:

- initial recipe setup support
- admin configuration
- a short onboarding session
- launch support for the first homes

Suggested concession:

- if Connaught proceeds to a full rollout, credit this fee against the first full rollout invoice

## Full Rollout Option

### Group Licence For All 6 Homes

- GBP 995 per month

Included:

- access across all homes
- hosting and maintenance
- ongoing support
- bug fixes
- minor feature refinements
- recipe access management
- continued platform improvements

This is the cleanest long-term option because it is easy to understand internally and avoids per-home admin complexity.

## Alternative If They Prefer Phased Adoption

### Per Home Rollout

- GBP 195 per home per month
- minimum 3 homes

This works if leadership wants to expand gradually rather than move to a full group rollout immediately.

## Why This Is Appealing

This structure makes the proposal feel commercially safe.

- The pilot is affordable enough to trial without a major approval barrier.
- Leadership gets a defined period to judge real value.
- The company can measure benefit before making a bigger commitment.
- The full rollout price still feels modest when spread across 6 homes.

## Suggested Talking Point

I would suggest presenting it like this:

> The best way to assess this is through a short, low-risk pilot. If the teams find it genuinely useful and leadership can see the operational value, we can then move to a wider rollout across the homes with a simple monthly group fee.

## Recommendation

My recommendation is to lead with the 60-day pilot and position the full rollout only as the next step if the pilot proves its value.

That approach is usually easier to accept because it feels practical, measured, and low pressure.
